# 1C Order Webhook Service

HTTP-сервис для 1С:Предприятие 8.3, предназначенный для приёма заказов из внешних систем (Telegram-ботов, интернет-магазинов, лендингов) по протоколу REST/JSON.

## Возможности
- Приём POST-запросов в формате JSON.
- Автоматический поиск контрагента по номеру телефона (с нормализацией номера) или создание нового.
- Пакетный поиск номенклатуры по коду (`SKU`) одним запросом к БД без нагрузки в цикле (решена проблема N+1).
- Транзакционная запись документа `ЗаказКлиента` с откатом при ошибках или пустом списке валидных товаров.
- Логирование сбоев в Журнал регистрации 1С (`API_Orders`).

## Пример запроса (POST)

```json
{
  "external_id": "TG-90412",
  "phone": "+7 (999) 123-45-67",
  "client_name": "Иван Иванов",
  "items": [
    {
      "sku": "00-00000123",
      "qty": 2,
      "price": 1500
    }
  ]
}
```

## Примеры ответа

**Успешное создание (200 OK):**
```json
{
  "ok": true,
  "order_num": "0000-000145"
}
```

**Ошибка валидации (400 / 422) или сбой сервера (500):**
```json
{
  "ok": false,
  "error": "No valid items found in nomenclature"
}
```
